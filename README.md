**Quiz Game: "Trivia Trek"**
_In "Trivia Trek," players progress through a series of quiz questions from various categories. Each
correct answer earns points and allows the player to move to the next question. The game continues
until a set number of rounds are completed, or a "game over" condition is met (e.g., three incorrect
answers)._
